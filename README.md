# PREDICTRA-AI

## AI-Based Predictive Maintenance System

### About the Project
PredictRA is an AI-powered predictive maintenance system that analyzes
machine operating parameters to estimate machine failure risk.

### Parameters Used
- Temperature
- Vibration
- Current
- RPM

### Features
- Failure prediction
- Failure probability
- Machine health/risk status
- Maintenance recommendation
- Streamlit dashboard

### Technologies
- Python
- FastAPI
- Streamlit
- Scikit-learn
- Pandas
- NumPy

### How to Run

pip install -r requirements.txt

python train_model.py

streamlit run app.py
